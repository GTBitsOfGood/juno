Juno's email service sends mail through **your** SendGrid account. You give Juno a SendGrid API key once, register a domain and a sender, and from then on every email is one SDK call.

<Note>
  This page uses the SDK. To call the routes directly, see the **Email** section
  of the [API reference](/api-reference/introduction). All examples assume
  you've already [initialized the SDK](/getting-started).
</Note>

## What you need first

- A Juno project and API key (see [Getting started](/getting-started)).
- A [SendGrid](https://sendgrid.com) account and an API key with permission to send mail and manage sender authentication.
- Access to your domain's DNS settings.

## 1. Connect your SendGrid key

```ts
await juno.email.setupEmail({
  sendgridKey: 'SG.your-sendgrid-api-key',
});
// { success: true }
```

You can also do this in the dashboard on your project's **Settings** page (`/projects/<project id>/settings`), which also lets you update the key later.

To read your current config back:

```ts
const config = await juno.email.getEmailConfig('<your project id>');
```

The config has an `id`, the `environment` (taken from your API key), the `sendgridKey`, and your registered `domains` and `senders`.

## 2. Register your domain

Registering a domain keeps your mail out of spam folders.

```ts
const result = await juno.email.registerDomain({
  domain: 'yourcompany.com',
  subdomain: 'mail', // optional: subdomain to send from
});
```

The response includes three DNS records (`mailCname`, `dkim1`, `dkim2`) you need to add to your domain.

## 3. Add the DNS records and verify

For each of the three records, add a **CNAME** in your DNS provider using the `host` and `data` values from step 2. DNS can take up to 48 hours to propagate. Once the records are in, verify:

```ts
const result = await juno.email.verifyDomain({
  domain: 'yourcompany.com',
});
```

You get the same shape back as in step 2, with `valid` telling you whether the domain verified.

## 4. Register a sender address

This is the address that shows up in the "From" field. SendGrid requires a physical mailing address for CAN-SPAM compliance.

```ts
await juno.email.registerSenderAddress({
  email: 'noreply@yourcompany.com',
  name: 'Your Company',
  replyTo: 'support@yourcompany.com', // optional, defaults to the sender email
  nickname: 'Your Company Notifications',
  address: '123 Peachtree St',
  city: 'Atlanta',
  state: 'GA',
  zip: '30303',
  country: 'US',
});
```

## 5. Send an email

Your email service has to be set up, your domain verified, and your sender registered before this works.

```ts
await juno.email.sendEmail({
  sender: { email: 'noreply@yourcompany.com', name: 'Your Company' },
  recipients: [{ email: 'recipient@example.com', name: 'Recipient Name' }],
  subject: 'Welcome to our service',
  contents: [
    { type: 'text/plain', value: 'Hello! Thanks for signing up.' },
    { type: 'text/html', value: '<p>Hello! Thanks for signing up.</p>' },
  ],
});
// { success: true }
```

`contents` is a list of MIME types and bodies. Send both `text/plain` and `text/html` if you can.

### CC, BCC, and reply-to

You need at least one of `recipients`, `cc`, or `bcc`.

```ts
await juno.email.sendEmail({
  sender: { email: 'noreply@yourcompany.com', name: 'Your Company' },
  recipients: [{ email: 'recipient@example.com' }],
  cc: [{ email: 'cc@example.com' }],
  bcc: [{ email: 'bcc@example.com' }],
  replyToList: [{ email: 'support@yourcompany.com', name: 'Support' }],
  subject: 'Email subject',
  contents: [{ type: 'text/html', value: '<p>Hello!</p>' }],
});
```

## Email statistics

```ts
const stats = await juno.email.getStatistics({
  startDate: '2026-01-01', // required, YYYY-MM-DD
  endDate: '2026-01-31', // optional
  aggregatedBy: 'day', // optional: day, week, or month
  limit: 10, // optional
  offset: 0, // optional
});
```

Each entry in `stats.responses` has a `date` and SendGrid's counts: `requests`, `delivered`, `opens`, `clicks`, `bounces`, `blocks`, `spamReports`, `unsubscribes`, and friends. The dashboard shows the same data on your project's Email Service page (`/projects/<project id>/services/email`).

## Errors

| Status | What to check                                                                                    |
| ------ | ------------------------------------------------------------------------------------------------ |
| `400`  | A required field is missing or the wrong type, or you're creating something that already exists. |
| `401`  | Your API key is missing or doesn't have permission for this action.                              |
| `404`  | The ID or name you passed doesn't exist in Juno.                                                 |
| `500`  | Something broke on Juno's side. Ask for help in `#gt-infra-support`.                             |
