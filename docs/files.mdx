---
title: Files
description: Store and fetch files with presigned URLs, using your own S3-compatible or Azure storage.
---

Juno's file service doesn't hold your files. You register your own storage provider (S3, Backblaze B2 or anything S3-compatible, or Azure), and Juno hands you short-lived **presigned URLs** to upload and download directly from it.

<Note>
  This page uses the SDK. To call the routes directly, see the **File** section
  of the [API reference](/api-reference/introduction). All examples assume
  you've already [initialized the SDK](/getting-started).
</Note>

## How it's organized

- **File config**: one per project and environment (taken from your API key). Everything below hangs off it.
- **File provider**: the storage account Juno talks to (name, base URL, access keys, and type `S3` or `AZURE`).
- **File bucket**: a named container for files in a provider, like a folder.
- **File**: a file in a bucket that you can upload and download.

## 1. Set up the file config

```ts
await juno.file.setup();
// { success: true, config: { ... } }
```

Your project and environment come from your API key, so you don't pass them. You can read the config back at any time:

```ts
const config = await juno.file.getConfig('<your project id>');
// { id, environment, files: [...], buckets: [...] }
```

You'll need `config.id` for the next steps.

## 2. Register a file provider

```ts
await juno.file.registerProvider({
  providerName: 'my-s3',
  baseUrl: 'https://s3.us-west-004.backblazeb2.com',
  type: 'S3', // 'S3' or 'AZURE'
  accessKey: {
    publicAccessKey: process.env.S3_ACCESS_KEY_ID!, // accountName on Azure
    privateAccessKey: process.env.S3_SECRET_ACCESS_KEY!, // accountKey on Azure
  },
});
```

<Warning>
  Juno stores these credentials so it can manage your buckets and sign URLs for
  you. Load them from environment variables, never from source code.
</Warning>

## 3. Register a bucket

Juno creates the bucket in your provider and records it. Your config and provider must already exist.

```ts
await juno.file.registerBucket({
  name: 'my-bucket',
  configId: 0, // config.id from step 1
  fileProviderName: 'my-s3',
});
```

You can list your buckets with `juno.file.getBucketsByConfigIdAndEnv('<config id>')` and every file with `juno.file.getAllFiles('<config id>')`.

## 4. Upload a file

Uploading is two steps: ask Juno for a presigned URL, then upload straight to your provider with it.

```ts
const { url } = await juno.file.uploadFile({
  fileName: 'avatar.png',
  bucketName: 'my-bucket',
  providerName: 'my-s3',
  configId: 0,
  region: 'us-west-004', // optional
});

await fetch(url, { method: 'PUT', body: fileBytes });
```

See the [S3 presigned URL docs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/using-presigned-url.html) or [Azure SAS docs](https://learn.microsoft.com/en-us/azure/storage/common/storage-sas-overview) for provider details.

## 5. Download a file

```ts
const { url } = await juno.file.downloadFile({
  fileName: 'avatar.png',
  bucketName: 'my-bucket',
  providerName: 'my-s3',
  configId: 0,
  region: 'us-west-004', // optional
});

const response = await fetch(url);
```

## 6. Delete files and clean up

```ts
await juno.file.deleteFiles({
  bucketName: 'my-bucket',
  configId: 0,
  fileNames: ['avatar.png'],
});

await juno.file.deleteBucket({
  name: 'my-bucket',
  configId: 0,
  fileProviderName: 'my-s3',
});

await juno.file.deleteProvider('my-s3');
```

## Errors

| Status | What to check                                                                                                            |
| ------ | ------------------------------------------------------------------------------------------------------------------------ |
| `400`  | Fields are missing or the wrong type, an ID or name doesn't exist yet, or you're creating something that already exists. |
| `401`  | Your API key is missing or doesn't have permission.                                                                      |
| `404`  | The ID or name you passed doesn't exist in Juno.                                                                         |
| `500`  | Something broke on Juno's side. Ask for help in `#gt-infra-support`.                                                     |
