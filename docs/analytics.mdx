Juno analytics stores application events in Juno's database. It is separate from [email delivery statistics](/email#delivery-statistics), which come from SendGrid.

The gateway source includes routes for click, visit, input, and custom events, along with event retrieval. These events are associated with a project configuration and environment.

<Warning>
  **Integration status:** this guide intentionally leaves out an end-to-end SDK
  recipe until the supported SDK release and deployed event path have been
  verified together. The presence of a route in source does not establish that
  it is available in your deployed instance. The original migration work is
  tracked in [analytics database prework,
  #266](https://github.com/GTBitsOfGood/juno/issues/266).
</Warning>

You do not need to configure an external analytics provider's client or server keys. Provider setup from older Juno guides does not apply to Juno's database-backed events.
