Juno is Bits of Good's shared infrastructure. Almost every BoG project ends up needing the same handful of things: sending email, storing files, tracking what users do, and keeping track of who's allowed to touch what. Instead of every team wiring up SendGrid and S3 from scratch, Juno does it once behind a single API and an SDK.

Under the hood it's a NestJS monorepo of small services that talk over gRPC and sit behind one public API gateway. You never talk to the internal services directly. You talk to the gateway, either through [`juno-sdk`](https://www.npmjs.com/package/juno-sdk) (recommended) or plain HTTP.

## How it fits together

- **The dashboard** ([juno-dashboard](https://juno-dashboard.netlify.app)) is where people request accounts, superadmins approve them, and projects and API keys get managed.
- **The API gateway** is the public HTTP API. Every request is authenticated with your project's API key, which also tells Juno which project and environment you mean.
- **The SDK** ([juno-sdk](https://github.com/GTBitsOfGood/juno-sdk)) is a typed wrapper around the gateway. It's generated from the OpenAPI spec, so the [API reference](/api-reference/introduction) is always the source of truth.

## Where to start

If you've never used Juno, go straight to [Getting started](/getting-started). It walks you from "I don't have an account" to "my app made its first call" without needing to message anyone except whoever approves accounts.

If you want to hack on Juno itself, read [Local development](/local-development).
