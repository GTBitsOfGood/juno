title: Getting started

You need a Juno account, access to your team's project, and a project API key. These steps use hosted Juno; you do not need Docker.

## 1. Request an account

Open [Request account](https://juno-dashboard.netlify.app/request-account) and enter your name, email, and password.

- Choose **User** if you are joining an existing project.
- Choose **Admin** if you are requesting administrator access for a project, and enter its project name.

Submitting the form creates an account request. A Juno administrator must approve it before you can sign in; submitting it does not immediately grant access.

## 2. Open your project

Once approved, sign in to the [dashboard](https://juno-dashboard.netlify.app) and open your project from the project list. A project administrator or superadmin must link your user to the project if it is not already assigned.

If your project is missing, check with your project administrator that your account has been linked. Creating another account request will not add an existing user to a project.

Note the numeric project ID in the URL: `/projects/[id]`. You will use it in SDK calls.

## 3. Create an API key

In your project, open **API Keys** at `/projects/[id]/keys`.

1. Create a key with a description that identifies its use, such as `Backend development`.
2. Choose an environment. Service configuration is associated with this value, so use the same environment when configuring email or files.
3. Copy the revealed key and store it in your application's server environment as `JUNO_API_KEY`.

Key creation requires an admin with access to the project or a superadmin. If your role cannot create a key, your project administrator can create one for your application.

Keep the key out of source control and browser bundles. The examples below run on your server or in a local terminal.

## 4. Install the SDK

In your application directory:

```sh
pnpm add juno-sdk
```

These guides target the SDK API intended for `0.0.12`, including the optional service `credentials` argument. If that release is not yet available from your package registry, follow [Using a local SDK build](/local-development#using-a-local-sdk-build). An older installed version may not expose every method shown here.

## 5. Initialize Juno and make a first call

Create `first-call.ts` in your application:

```ts
import juno from 'juno-sdk';

async function main() {
  const apiKey = process.env.JUNO_API_KEY;
  const projectId = Number(process.env.JUNO_PROJECT_ID);

  if (!apiKey || !Number.isInteger(projectId) || projectId < 0) {
    throw new Error('Set JUNO_API_KEY and a numeric JUNO_PROJECT_ID');
  }

  juno.init({
    apiKey,
    baseURL:
      'https://api-gateway.whitesmoke-cea9a269.eastus.azurecontainerapps.io',
  });

  const project = await juno.project.getProject({ id: projectId });
  console.log(project);
}

main().catch((error) => {
  console.error(error);
  process.exitCode = 1;
});
```

Set `JUNO_API_KEY` to the key you copied and `JUNO_PROJECT_ID` to your project ID in your terminal's environment. For macOS, Linux, or WSL, replace these example values:

```sh
export JUNO_API_KEY='paste-your-key-here'
export JUNO_PROJECT_ID='12'
```

Run the script with a TypeScript runner:

```sh
pnpm dlx tsx first-call.ts
```

You should see your project's ID and name, for example:

```json
{ "id": 12, "name": "Your Project" }
```

This read-only lookup checks that the SDK can reach the gateway and find your project. The current project lookup route does not validate the API key; the email and file operations in the service guides require it.

Use the default import shown above and spell the option `baseURL` exactly. Initialize the SDK once before accessing its services.

## List your projects

`juno.project.getProjects(credentials)` calls `GET /project`. It requires **user credentials**, rather than just the project API key configured in `juno.init`.

After initialization, run this on your server with your Juno account email and password supplied through environment variables:

```ts
const email = process.env.JUNO_USER_EMAIL;
const password = process.env.JUNO_USER_PASSWORD;
if (!email || !password) {
  throw new Error('Set JUNO_USER_EMAIL and JUNO_USER_PASSWORD');
}

const { projects } = await juno.project.getProjects({ email, password });
console.log(projects);
```

Users and admins receive their assigned projects; a superadmin receives all projects. An account with no assigned projects receives an empty list. The method also accepts a user JWT string returned by `juno.auth.getUserJWT({ email, password })` as its credentials argument.

## Troubleshooting

| Problem                                    | Check                                                                                                                 |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| SDK says initialization is required        | Call `juno.init(...)` before accessing a service.                                                                     |
| Project lookup returns not found           | Use the numeric ID from the dashboard URL.                                                                            |
| A service returns unauthorized             | Check that the API key is current and belongs to the intended project. Management calls may require user credentials. |
| A service configuration is missing         | Configure that service for the same environment as your key.                                                          |
| A documented method or argument is missing | Check your installed SDK version or use the local SDK instructions.                                                   |
